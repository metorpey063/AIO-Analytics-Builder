Tableau Cloud: Personal Access Token

Create a PAT so AIO can publish datasources and create Pulse metrics.

How to create a PAT

1
Find your Server URL

Go to your Tableau Cloud site. The URL in your browser bar is the server URL — copy everything up to and including the domain (e.g. https://us-east-1.online.tableau.com). Don't include any path after the domain.

2
Find your Site Name

Look at your Tableau Cloud URL. If it's https://10ax.online.tableau.com/#/site/my-company/home then your site name is my-company. You can also find it under Settings → Site.

3
Create the token

Click your profile icon (top right) → My Account Settings → scroll to Personal Access Tokens → click "Create a new token".

4
Name it and copy the secret

Enter a name like aio-builder, then click Create. Copy the secret immediately — Tableau only shows it once. If you lose it, delete the token and create a new one.

How to create the ECA

1
Open App Manager

In Salesforce Setup, search "App Manager" → click "New External Client App" (top right).

2
Name the app

Set the name to AIO Analytics Builder and enter your email as the contact.

3
Enable OAuth

Expand "API (Enable OAuth Settings)", check "Enable OAuth", and set the Callback URL to:

http://localhost:8080/callback
4
Add OAuth Scopes

Under "Available OAuth Scopes", find and add each of these:

  • api — Manage user data via APIs
  • sfap_api — Access the Salesforce API Platform
  • cdp_query_api — Perform SQL queries on Data Cloud
  • cdp_ingest_api — Manage Data Cloud Ingestion API
  • refresh_token — Perform requests at any time
5
Flow Enablement

Under "Flow Enablement", check "Enable Authorization Code and Credentials Flow".

6
Security settings

Leave "Require Proof Key for Code Exchange (PKCE)" checked — AIO supports it. No other changes needed.

7
Get Consumer Key & Secret

Click Create. Then go to the app's Settings tab → OAuth Settings → "Consumer Key and Secret". You may need to verify your identity. Copy both values and paste them in the form.

8
Create Ingest API Connector

Required for Tableau Next builds. In Salesforce Setup, search "Ingestion API" (under Data Cloud → External Integrations). Click "New", name it:

analytics_builder_demo

Complete any required fields and save. AIO will auto-discover this connector during builds.

9
Enable Tableau Next + AI Features

Required before building. In Salesforce Setup:

  • Search "Tableau" → enable Tableau Next
  • Search "Einstein" → enable Einstein Generative AI
  • Enable Tableau Pulse AI if using Concierge

MCP Server Setup (optional, recommended)

The MCP enables high-quality dashboard creation with slim viz specs, Z layouts, and programmatic business preferences. To set up:

  • In Setup, search "MCP Servers" (under API Catalog) → Salesforce Servers tab → find Tableau Next Beta → click Activate
  • The MCP Servers page is under Setup → API Catalog → MCP Servers

Create the MCP External Client App:

  • Setup → External Client App Manager → New External Client App
  • Name: AIO MCP Client
  • Enable OAuth, Callback URL: http://localhost:8080/callback
  • Scopes: mcp_api + refresh_token
  • Uncheck: Require secret for Web Server Flow, Require secret for Refresh Token Flow
  • Check: Require PKCE, Issue JWT-based access tokens for named users
  • Copy the Consumer Key and paste it in the MCP Client ID field below

Step 3: Salesforce OAuth Authorization

Click below to open a browser window where you'll log in to Salesforce and authorize AIO. The refresh token will be saved automatically.

1 Make sure your default browser is logged into the correct Salesforce org
2 Click "Run OAuth Flow" — a browser tab will open
3 Click "Allow" on the Salesforce authorization page
4 The browser will redirect to localhost — the token is captured automatically

Note: It can take up to 10 minutes for a new External Client App to become active after creation. If the OAuth flow fails immediately, wait a few minutes and try again.

Setup Guide

1
Tableau Cloud PAT

Profile icon → My Account Settings → Personal Access Tokens → Create. Copy the secret immediately.

2
Create the Salesforce External Client App

In Salesforce Setup, search "App Manager" and click "New External Client App" (top right).

  • Set the App Name to AIO Analytics Builder
  • Enter your email as the Contact Email
  • Expand "API (Enable OAuth Settings)"
  • Check "Enable OAuth"
  • Set Callback URL to: http://localhost:8080/callback
  • Under Available OAuth Scopes, add all five:
    • Manage user data via APIs (api)
    • Access the Salesforce API Platform (sfap_api)
    • Perform SQL queries on Data Cloud data (cdp_query_api)
    • Manage Data Cloud Ingestion API data (cdp_ingest_api)
    • Perform requests at any time (refresh_token)
  • Under Flow Enablement, check "Enable Authorization Code and Credentials Flow"
  • Under Security, leave "Require Proof Key for Code Exchange (PKCE)" checked
  • Click Create
  • Go to the app's Settings tab → OAuth Settings → click "Consumer Key and Secret"
  • Copy the Consumer Key and Consumer Secret and paste them in the form
3
Run the OAuth Flow

Click "Run OAuth Flow" below. A browser tab will open — log into Salesforce and click Allow. The refresh token saves automatically.

Note: New ECAs can take up to 10 minutes to become active. If it fails immediately, wait and retry.

4
Create Ingest API Connector

Required for Tableau Next demo builds.

  • In Salesforce Setup, search "Ingestion API" (under Data Cloud → External Integrations)
  • Click "New" (top right)
  • Enter the connector name: analytics_builder_demo
  • Complete any other required fields and click Save
5
Enable Tableau Next + AI Features

Required before building demos. In Salesforce Setup:

  • Search "Tableau" → click into Tableau settings → enable Tableau Next
  • Search "Einstein" → enable Einstein Generative AI
  • Enable Tableau Pulse AI if you plan to use Concierge

MCP Setup (optional — premium dashboards)

The MCP enables high-quality Z layout dashboards, programmatic business preferences, and slim viz specs.

Step A — Activate the MCP server:

  • In Setup, search "MCP Servers" (under API Catalog)
  • Click the Salesforce Servers tab
  • Find "Tableau Next Beta" in the list
  • Click the dropdown arrow on the right → click Activate

Step B — Create the MCP External Client App:

  • In Setup, go to External Client App Manager → click "New External Client App"
  • Set the App Name to AIO MCP Client
  • Enter your email as the Contact Email
  • Expand "API (Enable OAuth Settings)" and check "Enable OAuth"
  • Set Callback URL to: http://localhost:8080/callback
  • Under Available OAuth Scopes, add these two (search for them):
    • Perform requests at any time (refresh_token, offline_access)
    • Access Salesforce Hosted MCP Servers (mcp_api)
  • Under Flow Enablement, check "Enable Authorization Code and Credentials Flow"
  • Under Security:
    • Uncheck: Require secret for Web Server Flow
    • Uncheck: Require secret for Refresh Token Flow
    • Uncheck: Enforce Refresh Token IP Allowlist
    • Check: Require Proof Key for Code Exchange (PKCE)
    • Check: Issue JSON Web Token (JWT)-based access tokens for named users
  • Click Create
  • Go to the app's Settings tab → OAuth Settings → "Consumer Key and Secret"
  • Copy the Consumer Key and paste it in the MCP Consumer Key field

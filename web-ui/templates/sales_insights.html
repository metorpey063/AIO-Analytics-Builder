Deploy Sales Insights

Deploy a standalone copy of Tableau Next Sales Insights to any org with Data Cloud: six dashboards, 68 vizzes and the semantic model behind them, on synthetic data dated relative to today. The org doesn't need the managed Sales Insights app or any CRM data.

Runs from Claude Code for now

This skill doesn't have a web UI yet. In Claude Code, type /deploy-sales-insights: it asks which org, confirms what it will create, and runs the deploy (about 10–15 minutes). Or run the steps yourself in a terminal from the AIO folder:

What it creates

  • One workspace, "Sales Insights", with six dashboards: Sales Performance, Team Performance, Leaderboard, Sales Stage Progression, Sales Stage Conversion, Lead Analysis
  • One semantic model (136 calculations, 9 parameters, 7 metrics, 17 joins) and 68 vizzes
  • 15 si_* data streams on the connection's ingest connector

Afterwards, share the workspace in the UI: Share → All Internal Users → View (the API can't share it).

The demo story

  • Team Harbor is behind: Rachel Kim's team wins ~29% of closed deals vs ~42–44% for Summit and Ridge, with smaller deals.
  • Pushes and stalls cluster on two Harbor reps, Lucas Moreau and Mateo Silva (Sales Stage Progression, Leaderboard).
  • Lead conversion runs from ~60% (Referral) to under 10% (Trade Show) (Lead Analysis).
  • Open deals with no activity fill the Leaderboard "No Activity" tab.

The data is anchored to the day it's generated. If the deploy is more than a couple of weeks old, refresh it before a meeting (reset, then deploy).

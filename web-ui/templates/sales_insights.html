Deploy Sales Insights

Deploy a standalone copy of Tableau Next Sales Insights to any org with Data Cloud: six dashboards, 68 vizzes and the semantic model behind them, on synthetic data dated relative to today. The org doesn't need the managed Sales Insights app or any CRM data.

1 Org

Pick by org URL, not name: never the Tableau Next & Slack org (the source; the deploy refuses it). Add an org on Connections.
Read-only: login, Data Cloud ingest connector, and any earlier deploy.

2 Deploy

  • One workspace, "Sales Insights", with six dashboards: Sales Performance, Team Performance, Leaderboard, Sales Stage Progression, Sales Stage Conversion, Lead Analysis
  • One semantic model (136 calculations, 9 parameters, 7 metrics, 17 joins) and 68 vizzes
  • 15 si_* data streams on the connection's ingest connector
About 10–15 minutes, mostly Data Cloud. If it stops, fix the cause and press Deploy again: it resumes and never recreates finished assets.

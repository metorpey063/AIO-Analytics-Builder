Transfer Assets

Copy Tableau Next dashboards from one org to another: the dashboards, their vizzes, the semantic model, calculations and metrics. When the target org doesn't have the data yet, the transfer creates the data stream and copies the rows over. The source org is only read, never changed.

1 Orgs

Pick by org URL, not name. The target needs Data Cloud and an ingest connector (set up on Connections).

2 Dashboards

Pick a source org to list its dashboards.
Every selected dashboard goes into this one new workspace and shares one semantic model. Run the same transfer again with the same name to resume it.
Read-only: packages the dashboards from the source and checks what the target needs for the data. 1–2 minutes.

3 Transfer

Run "Check transfer" first. 5–15 minutes, mostly Data Cloud creating the stream and loading rows. If it stops, press Transfer again: finished steps are skipped. 

    







    
Remove

    

        
        Uses the target and workspace name above. Deletes only the dashboards, vizzes, workspace and semantic model this transfer created. The copied data stream stays, and nothing else in either org is touched.

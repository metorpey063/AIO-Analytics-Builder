  AIO Analytics Builder — Quick Start
═══════════════════════════════════════════════════════


  OPTION 1: Download from GitHub (recommended)
  ─────────────────────────────────────────────
  1. Go to: https://github.com/metorpey063/AIO-Analytics-Builder
  2. Click the green "Code" button (top right)
  3. Click "Download ZIP"
  4. Unzip the downloaded file
  5. Open the unzipped folder
  6. Double-click "AIO Installer.app"

  If macOS shows a security warning:

    Method A: Right-click "AIO Installer.app" → Open → click "Open"

    Method B: If that doesn't work:
      1. Open System Settings (Apple menu → System Settings)
      2. Go to Privacy & Security
      3. Scroll down — you'll see:
         "AIO Installer was blocked from use because
          it is not from an identified developer"
      4. Click "Open Anyway"
      5. Enter your password if prompted

    Method C: Open Terminal and paste:
      xattr -cr ~/Downloads/AIO-Analytics-Builder-main
      Then double-click "AIO Installer.app" again.

    You only need to do this once — macOS remembers.

  The installer will:
    • Set up Python and dependencies
    • Put "AIO Builder" on your Desktop
    • Launch the Web UI automatically


  OPTION 2: One-Line Terminal Install
  ────────────────────────────────────
  Open Terminal (Spotlight → type "Terminal" → Enter)
  and paste:

    curl -sL https://raw.githubusercontent.com/metorpey063/AIO-Analytics-Builder/main/install_remote.sh | bash


  LAUNCH (every time after install)
  ──────────────────────────────────
  Double-click "AIO Builder" on your Desktop.

  It automatically:
    • Checks for updates (~2 seconds)
    • Starts the web server
    • Opens your browser to http://localhost:5100

  If macOS blocks it on first launch:
    Right-click → Open → click "Open"
    Or: System Settings → Privacy & Security → "Open Anyway"


  FIRST TIME SETUP
  ─────────────────
  1. The Web UI opens → click "Setup"
  2. Enter a connection name (e.g. "My Demo Org")
  3. Choose your platforms (Tableau Cloud, Tableau Next)
  4. Set up your Claude AI key:
     Open Terminal → run "claude setup-token" → paste the key
  5. Follow the guide to create your Salesforce External
     Client App and run the OAuth flow

     IMPORTANT: Make sure your browser is logged into the
     correct Salesforce org BEFORE clicking "Run OAuth Flow".
     If you're logged into a different org, the wrong token
     will be saved and the connection will fail.

  6. Click "Verify" to test all connections


  TROUBLESHOOTING
  ───────────────
  Server won't start?
    Close Terminal and double-click AIO Builder again.

  Need a clean update?
    Open Terminal and paste:
    cd ~/AIO-Analytics-Builder && git reset --hard origin/main && git pull

  Need a full rebuild?
    Open Terminal and paste:
    cd ~/AIO-Analytics-Builder && rm -rf .venv && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

  Lost your connections?
    They're saved in ~/AIO-Analytics-Builder/config.json
    and survive updates.


  WHAT AIO DOES
  ─────────────
  • Generates story-driven demo data with engineered signals
  • Publishes to Tableau Pulse, Tableau Next, or CRM Analytics
  • Creates dashboards, metrics, and visualizations automatically
  • Produces a walkthrough document for the demo

  Web UI: http://localhost:5100
  GitHub: https://github.com/metorpey063/AIO-Analytics-Builder
